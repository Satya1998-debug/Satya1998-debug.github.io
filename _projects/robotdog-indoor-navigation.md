Master's thesis at the [Institute for Automation and Software Systems](https://www.ias.uni-stuttgart.de/), University of Stuttgart (since June 2024).

The robot is a quadruped. The task is indoor navigation with a person in the loop: the robot has to move through rooms and traverse doors, and a person should be able to tell it what to do in speech and hear a spoken reply.

The work ties together pieces that already exist rather than replacing them:

- Camera perception, SLAM, and motion estimation for real-time navigation
- A speech interface built with large language models, for commands and feedback
- Real-time control in ROS and Python

Skills: Python, ROS, SLAM, large language models, real-time control, human–robot collaboration.
