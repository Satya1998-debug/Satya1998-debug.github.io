[Hack NOW! 2024](https://de.nttdata-solutions.com/hack-now-2024) by NTT DATA Business Solutions with Silbury Deutschland GmbH, in Bonn (September 2024). Our team reached the pre-finals and took 3rd prize.

Big events put a lot of cars on the same roads at the same time. We built a web API that matches fans travelling to the same event by location, and adds rewards so sharing a ride is worth it. Fewer cars means less traffic and lower CO₂ emissions.

Code: [Eco-Riders](https://github.com/Satya1998-debug/Eco-Riders).
