Theses

  • 11.2025 - Current
    RoboDog Guide: Human-Robot Teaming for Indoor Navigation [Master Thesis]
    Institute of Industrial Automation and Software Engineering (IAS), University of Stuttgart | Supervisors - Prof. Andrey Morozov, Joachim Nilsen Grimstad
    • Turned a Unitree Go1 into a speech-driven indoor guide that handles doors on its planned route safely. Project page
    • Layer I (agent) - offline LangGraph workflow with local Qwen models, RAG over web-scraped university data, Vosk speech recognition and pyttsx3/eSpeak speech output.
    • Layer II (bridge) - approved tool calls become ROS commands via roslibpy and the rosbridge WebSocket, with a custom navigation service, human approval before navigation and structured execution feedback.
    • Layer III (robot) - integrated a Jetson AGX Orin, RealSense D455 and RoboSense LiDAR with the Go1; LIO-SAM, AMCL, move_base, NavfnROS and TEB for mapping, localisation and planning.
    • Door perception - fine-tuned YOLO11m (single doors, double doors, handles) and TensorRT-accelerated Depth Anything V2 for glass doors; RGB-D back-projection and RANSAC plane fitting for door centre, width and normal. mAP@0.5 of 0.901 at 5 Hz on the Jetson Orin.
    • Door Coordinator state machine - pre-door pose, door state and passability check, human-in-the-loop with VLM scene understanding, post-door pose, resume goal.
    • Skills
      • Python, ROS Noetic, LangGraph, Ollama, RAG, YOLO11, Depth Anything V2, TensorRT, Open3D, SLAM, NVIDIA Jetson Orin
  • 11.2024 - 05.2025
    A Framework for Cardiac MRI Feature Extraction And Visualization [Research Thesis]
    Universitätsklinikum Tübingen & ISS, University of Stuttgart | Grade - 1.0
    • Developed a framework for cardiac feature extraction and visualization of cardiac MRI data.
    • Evaluated the framework using datasets from NAKO and UK Biobank.
    • Integrated deep learning models like U-Net for segmentation, MOPNet for motion estimation, and DeepStrain's Green-Lagrange strain module for strain tensor calculation.
    • Used the open-source framework PyRadiomics for radiomics feature extraction.
    • Features like ventricular volumes, diameters, stroke volumes, ejection fractions and myocardial strain were extracted and visualized using the AHA bullseye.
    • Interactive dashboard in Streamlit to facilitate clinical diagnosis and research.
    • Skills
      • Python, PyTorch, TensorFlow, PyRadiomics, Streamlit, Plotly, Pandas, NumPy, Scikit-learn
  • 07.2019 - 05.2020
